# Design hypotheses

This directory contains attributed, non-normative proposals that may inform
future experiment design. A note here does not change `TARGET.md`,
`RED_LINES.md`, a frozen experiment, or an acceptance specification.

Before a proposal can support a scientific claim, it must be converted into a
prospectively frozen experiment with a cheapest falsifier, controls, task
order, scoring rule, resource budget, and promotion gate under
`docs/WORKFLOW.md`.

Notes preserve individual authorship so that distinct contributions are not
collapsed into unattributed feedback. Authorship does not grant control over
the evidence used to evaluate a proposal: actor, world, substrate, and
evaluator authority remain separate.
