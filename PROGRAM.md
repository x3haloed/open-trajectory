# Research program

The developmental coordinate is encounter index, not wall-clock time:

```text
prospective prediction or action
→ independently retained world response
→ measured discrepancy
→ permitted persistent update
→ complete context reset
→ later held-out prediction or action
```

## Program A — Contact-Causal Learning

Build the evaluation harness before choosing a preferred memory substrate.
Compare no persistence, equal-budget transcript retrieval, semantic retrieval,
Watch, and candidate substrates over hidden-rule, executable-software, and
noisy probabilistic domains. Require structural holdouts, a regime shift,
cold-instance inheritance, and causal ablations.

Initial sequence:

- **OT-0001:** prove reset, sealing, evidence, and leak controls.
- **OT-0002:** characterize Watch as an unchanged causal baseline.
- **OT-0003:** test predictive commitments plus outcome and revision history.
- **OT-0004:** test whether the inheritance selector itself can improve.
- **OT-0005:** test inheritance in a clean model instance.

## Program B — Self-Authored Durable Goals

Separate goal, plan, subgoal, and current action. A goal contract records its
value thesis, completion predicate, constraints, progress evidence, revision
conditions, and surrender conditions. Continuation is voluntary; completion is
an externally judged evidence claim.

Initial sequence:

- **OT-0006:** isolate bounded-slice completion failure with a human goal.
- **OT-0007:** test voluntary goal formation from procedural orientation.

## Program C — TAAA

Represent authority as a versioned capability vector. A capability petition
records the obstruction, smallest requested delta, predicted improvement,
independent test, blast-radius bound, expiration, and rollback trigger.

Initial sequence:

- **OT-0008:** test a minimal legitimate capability petition.
- **OT-0009:** compare impossible tasks with and without lawful recourse.
- **OT-0010:** reverse a promoted boundary after a regime shift.

The complete target path is:

```text
contact
→ lower held-out prediction error
→ self-authored falsifiable goal
→ sustained pursuit
→ diagnosed authority bottleneck
→ minimal petition
→ independent canary
→ evidence-gated expansion
→ contradictory later contact
→ revision or revocation
→ preserved correction capacity
```
