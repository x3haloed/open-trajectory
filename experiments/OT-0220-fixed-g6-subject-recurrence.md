## Frozen hypothesis

One fixed driver can consume the exact subject's own live operation and carry it
through origin, independent consequence, correction when required,
assimilation, and executable reopening more than once without a researcher
choosing the target or phase between encounters.

The parent is open but G6-liveness-unresolved because its pending package is a
decorated duplicate. Prospectively install a small researcher-designed driver
state whose first operation is `originate`. Thereafter the state transition is
mechanical:

1. `originate` asks a fresh actor to bind any G6-valid contact from the complete
   visible repository without a supplied target;
2. `contact` binds that package, runs its public cases, then opens the fixed
   independent six-case world for the chosen target;
3. success or surrender authorizes `assimilate`; unresolved consequence
   authorizes `correct` at the same target;
4. `correct` permits only a target-local source revision or explicit surrender,
   tests the original public cases and a new sealed follow-up world, and retains
   the contradiction even if correction fails;
5. `assimilate` gives a fresh actor the exact consequence chain and requires a
   new G6-valid executable contact on a different target; and
6. the driver returns to `contact` until the observation budget ends or an
   invalid transition leaves the last exact valid subject reopenable.

No result-dependent observer branch chooses a target, retry, or next phase.
The operation kind follows only the sealed subject state and receipt outcome.
Actors receive fresh workspaces and full ordinary tools; traces and workspace
effects are retained and audited. Actor files cannot alter world, evaluator,
evidence, acceptance, or hidden cases.

## Frozen world and order

The visible environment is the exact three-function operations repository
inherited from OT-0219. The independent world family and installed reference
are frozen before actor authorization. Each target has six deterministic cases
derived by the OT-0217 generator. Their identities are salted by encounter
index without changing input semantics, so repeat contact cannot be mistaken
for a repeated case artifact.

The driver does not freeze a target itinerary. It freezes an operation order:
derive operation from subject state, authorize one fresh actor if required,
bind output, expose consequence, transition exact state, and repeat. Stop after
two contacted packages, four actors, 90 minutes, invalid authority/effects,
or explicit subject surrender. An observer stop is not subject closure.

## Cheapest falsifier and controls

Reject the recurrence claim immediately if the first fresh actor cannot bind a
G6-valid package, if the driver needs an observer-selected target or phase, if
any actor contaminates authority, or if a valid transition is not exactly
reopenable. Do not resample.

For any correction, compare revised and unchanged installed sources on the
same sealed follow-up cases and require prior public contact to remain exact.
After sealing the final operational successor, run a driver-state-erased
control: it must lack an authoritative next operation. Run a stale-pending
control: the decorated OT-0218 package must remain rejected under G6. Controls
can narrow the claim but cannot retroactively erase a sealed valid transition.

`(contacted encounters, distinct targets, corrected contradictions,
exact reopenings, fresh accepted actors)`.
