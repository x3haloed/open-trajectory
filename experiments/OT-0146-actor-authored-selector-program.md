# OT-0146 — actor-authored selector program

- **Status:** frozen; not run
- **Evidence class:** exploratory-only
- **Target:** replace OT-0145's researcher-named selector feature vocabulary
  with one retained actor-authored ranking program while preserving the exact
  contradiction, controls, capability floors, and later reuse
- **Parent:** exact OT-0145 open subject
- **Actor budget:** one fresh selector-program author, two fresh deadline
  portfolio authors, and one fresh exact-program reuse verifier; no replacement
- **Observer budget:** one complete driver invocation; 110 minutes

## Open program interface

Give the program author the exact first OT-0145 portfolio and comparative
deadline consequence, the subject position, and a small total JSON expression
language. Do not publish `constraint_compatible`, a feature list, or a required
priority. The actor may edit only `selector-program.json`.

The program is an ascending lexicographic score vector. Its pure primitives can
read public pass status, simulate a candidate at the context maximum, read the
hard deadline, compare values, count strategy fields, and read candidate id.
The observer interprets the expression tree; actor code is never executed.
Require the program to choose the exact first hidden-passing alternative and to
pass an executable checker. Bind exact program bytes, trace, parent identity,
and cause receipt before any held-out portfolio exists.

## Held-out comparison and reuse

After binding, let a fresh actor author a second two-family deadline portfolio.
Bind actor-authored program, exact OT-0145 selector, and exact pre-correction
OT-0142 selector under identical information before new hidden histories.
The program and OT-0145 selector must both choose deadline-capped cadence and
pass all three shifts plus control; the old selector must choose pure relative
cadence and fail every shift while preserving control.

Replay exact q256 reserve and ordinary unconstrained recovery floors. Install
the selector program as additional subject capability, preserving the readable
v3 selector rather than erasing it.

Then let a third fresh actor author another portfolio. Give a fourth fresh actor
the installed exact program, bound portfolio, and mutation envelope. It may edit
only `program-reuse.json` and must select reuse without changing program bytes.
Bind that choice before new hidden histories. The reused program must select
capped cadence and pass every shift; the pre-correction selector control must
fail every shift. Seal the active successor before opening the control.

Require all three established capability roles, v3 selector, and exact selector
program to survive. The final subject remains open toward cross-world transfer
of actor-authored selection semantics.

Stop at the first identity, grammar, checker, audit, binding, hidden comparison,
floor, installation, reuse, or opening failure. Never resample an actor.

Passing would establish bounded actor authorship and retention of selector
feature computation inside a researcher-designed total expression grammar. It
would not establish arbitrary code evolution, cross-world program transfer,
subject-selected worlds, or autonomous amendment-language invention.
