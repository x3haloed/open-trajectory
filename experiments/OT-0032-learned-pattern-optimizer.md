canary outputs. **Risk frontier:** whether learned pattern state, rather than a
researcher-authored mode, crosses the complete update→retention→fresh restore→
selection→prediction→error path and later reverses.

The central truth is: completed outcomes score proposals; the optimizer commits
the lexicographically first minimum-error pattern state; only that snapshot
crosses into a fresh instance and causes later selection.
