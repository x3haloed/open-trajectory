# OT-0032 — Deterministic learned-pattern selector walking skeleton

- **Status:** passed as frozen; publication handoff repaired prospectively
- **Evidence class:** public-reconstructible mechanism feasibility
- **Target authority:** none; no OT-1 or E4 authority
- **Predecessor:** OT-0031 closed direct LLM synthesis and bounded feedback

## Realization contract

**Capability:** completed independent query outcomes cause a generic optimizer
to commit a previously unspecified six-pattern selector; a fresh restored
instance applies it for lower future error; later contact makes that learned
criterion harmful; another fresh optimizer commits a different selector that
passes a later canary.

**Envelope:** the public sixteen-pattern binary world, exact six-example budget,
deterministic parity predictor, exhaustive six-pattern proposal family, and
frozen fixed controls. **Exclusions:** hosted-actor reliability, cross-domain
generality, OT-1 promotion, and E4 authorization. **Evidence horizon:** exact
public inputs, state identities, update receipts, controls, ablation, and
canary outputs. **Risk frontier:** whether learned pattern state, rather than a
researcher-authored mode, crosses the complete update→retention→fresh restore→
selection→prediction→error path and later reverses.

The central truth is: completed outcomes score proposals; the optimizer commits
the lexicographically first minimum-error pattern state; only that snapshot
crosses into a fresh instance and causes later selection.

## Cheapest falsifier and frozen gates

Reject unless the neutral earliest-six state begins at eight errors; exactly
8,008 six-pattern candidates are scored on completed outcomes; the learned
state changes and reaches zero on a clean canary; later archive corruption of
the learned patterns raises unchanged-state error to at least twelve; a second
learned state changes and reaches zero on a later canary; the unchanged-state
ablation loses at least eight; and candidate aggregate error beats every frozen
earliest/latest/extremes/even/odd/no-persistence control by at least eight.

This is a deterministic walking skeleton, not a target claim. The optimizer
family is researcher-authored, while the retained pattern criterion is learned.
Execution is forbidden until a clean implementation commit and separate run-
lock commit bind every authority. OT-0032 is not altered after execution.
