## Frozen temporal world

Each task has two mechanically derived opaque cue tokens and a repeated public
choice between `left` and `right`. The final two events have identical numeric
features and expose only their side; cue history is not part of either event.
Every real four-weight setting and every deterministic stateless policy must
therefore choose the same side across histories. Heldout sets are balanced four
left/four right, so all such policies incur four errors.

Three regimes change significance in kind:

1. choose left exactly when the count of the first opaque cue is odd;
2. choose left exactly when the cue sequence ends with first-cue/second-cue;
3. choose left exactly when the second-cue count is one modulo three.

Regime-two heldouts are mechanically selected so the first regime's minimal
machine is wrong on all eight choices. Regime-three heldouts are balanced and
make the second machine wrong on at least four. Cue identities, diagnostic and
heldout sequences, row order, and event order are mechanically varied across
sixteen cases while preserving these certificates.

Contact contains fifteen diagnostic sequence bundles. Each bundle repeats one
sequence across four independently identified choice presentations and records
completed consequences, making a complete row larger than 512 bytes and the
full raw record larger than 1,024 bytes. At most one complete row fits the
active inheritance budget. A controller-private library of at least twelve
small temporal hypotheses must certify that every allowed exact-row projection
leaves at least two contact-consistent hypotheses with different heldout
behavior, while all fifteen bundles uniquely identify the active reference.
Heldout sequences are absent from contact.

## Frozen generic carrier and controls

The carrier is a bounded JSON finite-state transducer. It contains an actor-
chosen start-state identifier and an actor-chosen list of states. Each state has
an actor-chosen identifier, one output side, and exactly one next-state edge for
each public opaque cue. The generic interpreter validates determinism,
completeness, reachability, bounded bytes/state count, exact cue authority, and
output type, then runs the machine from its start state over each cue sequence.
It supplies no parity, suffix, counting, regime, desirable-state, transition,
or update menu. The carrier and interpreter are explicit researcher-built
causal exoskeletons; hidden machines prove opportunity only.

Freeze empty, digest, every allowed exact-row replay, always-left/right,
alternating-side, every stateless side policy, every real four-weight setting,
and every fixed reference machine across all three regimes. No fixed lineage
may pass the complete endpoint. Decisively collapse the hidden machine to one
state, reset it before every cue, delete one necessary transition, and delete
one actor-variable cue edge; each intervention must remove its advantage.

Reference updates require a completed contact receipt and contact-perfect
machine. Invalid, incomplete, unreachable, over-budget, or contact-imperfect
updates preserve the exact parent. Committed machines have immutable identity,
exact projection/restore, and rollback. The reference topology fingerprint
must change between every regime; changing only an output label is
insufficient.
