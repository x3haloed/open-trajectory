# OT-0296 — Post-correction renewed selection

- **Status:** rejected in zero-actor preflight
- **Evidence class:** exploratory-only
- **Parent:** exact OT-0295 corrected subject `90b6999c...`
- **Invocation:** two identical content-free openings

## Hypothesis

Successful recovered-world correction can resume self-directed pursuit without
researcher phase or target choice. One actor-free refresh should expose exactly
the two remaining surfaces; a fresh target-untold actor should choose either,
receive unresolved 2/6 consequence, and carry correction into the next turn.

## Frozen mechanism and gates

No mechanism changes. Use inherited projection refresh, opportunity selector,
shared content-isolation authority, sealed evaluator, and live derivation. Freeze
both possible target branches before live output. Each branch must be prompt
neutral, public-only, conformant, exact 2/6, and correction-routing. Refresh must
preserve invalidity/recovery lineage and the verified corrected target. Route
16/16 and identity 18/18 remain floors.

Any actor during refresh, preselected target, sealed leakage, actor/G10 failure,
retry, non-2/6 consequence, lost lineage, or failure to derive correction
rejects. Passing is renewed selection after correction, not completion of the
remaining world. Live output stays sealed until design and preflight are pushed.

## Result

The preflight rejects before live actors. Exact parent, actor-free refresh, two
remaining opportunities, both prompt-neutral 2/6 selection consequences,
correction routing, route 16/16, and identity 18/18 all pass. Both branches fail
only the shared content gate because it forbids every sealed reference source
from the current package. The subject now legitimately retains the independently
verified corrected source for the completed surface.

Preserve the rejection. The next design may scope the shared gate to unresolved
package surfaces, while direct controls must still reject reference source,
hidden cases, and full case collection for either remaining surface.
