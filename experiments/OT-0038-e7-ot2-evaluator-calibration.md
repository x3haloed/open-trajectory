## Hypothesis and causal opportunity

A controller can prospectively distinguish a worthwhile, falsifiable,
self-authored durable goal from a supplied goal, a locally attractive proxy,
and an unfinishable or non-corrigible contract without encoding a concrete
objective into the environmental packet. The same walking skeleton can make
the promoted OT-1 operation causally necessary for pursuit:

```text
raw service telemetry + procedural orientation, but no objective
→ actor proposes a structured value and evidence contract
→ controller admits or rejects it against sealed environmental truth
→ admitted contract projection crosses a complete context reset
→ consequence-trained selector chooses observations
→ actual OT-0014 ledger restores a changing route operation
→ plan changes after sealed invalidation while the goal remains fixed
→ partial repairs and proxy signals remain non-terminal
→ independent verification seals completion truth
→ a later fresh encounter reports the truthful terminal status
```

OT-0038 calibrates this path with controller oracles only. It does not run the
future goal author and cannot count oracle construction as self-authorship.

## Frozen task family and cheapest falsifier

The study exhausts all 384 signed coefficient criteria and all six eligible
parity/complement rule pairs already calibrated for OT-1. Each case presents
eight opaque offline services, public service values, two reversible repair
routes, independently receipted verification, and a three-intervention budget.
No packet contains a target subset, threshold, objective, or goal contract.

The four services labelled one by the initial hidden route rule receive the
four highest values in a case-specific order. The controller oracle therefore
authors the unique three-service maximum-value feasible contract, including
its value thesis, independent completion predicate, constraints, progress
evidence, revision conditions, and surrender conditions. Seven one-defect
counterfactual contracts must all be rejected. The same oracle-quality
contract is separately marked as actor-originated and researcher-given: both
remain downstream-valid, but only the former may satisfy the authorship gate.

Reject E7 if any task leaks the concrete goal, any oracle or temporal path
fails, any single-defect counterfactual passes, supplied authorship is credited,
the goal changes during two plan revisions, completion precedes a sealed
verification receipt, the exact unchanged-selector ablation chooses a correct
route in any regime, a control reconstructs the hierarchy, or any projection,
replay, order, identity, test, audit, or privacy gate fails.

## Temporal and causal controls

Every case has eight logical fresh encounters: admission, first repair, first
plan revision, second repair, second plan revision, third repair, independent
verification, and post-receipt judgment. The goal identity, target set, value
threshold, constraints, and terminal rules remain fixed. Plan identity changes
twice. Completion truth becomes available only after encounter seven and may be
claimed only in encounter eight.

For route choice, oracle selector snapshots traverse criterion/rule,
negated-criterion/complement-rule, and criterion/rule regimes. Their selected
observations enter the actual OT-0014 discrepancy-gated ledger. The exact
unchanged branch starts from the same selector and ledger parent but retains
the prior selector, forcing three wrong target routes in every regime. This is
the OT-1-to-pursuit causal edge; durable text alone cannot pass it.

No-persistence and recent-verbatim projections receive the same 512-byte
ceiling and current world receipt but must fail to reconstruct the governing
goal/plan/experiment/subtask hierarchy. A researcher-given oracle contract is
a positive downstream control, not OT-2 evidence.

## Promotion scope

If every frozen gate passes, E7 authorizes exactly one fresh candidate that
must generate its goal from the raw packet and then pursue it through fresh
actor contexts. A future candidate must derive its task only after a clean
implementation commit, must bind goal admission to the promoted OT-1 path, and
must include no-persistence, recent-verbatim, researcher-given-goal, and
unchanged-selector controls.

A pass establishes evaluator opportunity only. It does not establish goal
authorship, useful hosted behavior, OT-2, or cross-domain generality.
