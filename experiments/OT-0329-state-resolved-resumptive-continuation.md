Replace only that hidden lookup with a state-resolved capability binding. The
controller must find exactly one retained provider package whose world id and

let the inherited state driver choose every operation and let fresh actors
choose each target from the exact current projection. The expected operation

If turn-ending continuity and retained subject state are operational, the run

and repair its projection, then repeat for the remaining target. It will stop
open at the subject-derived `expand-environment` boundary, not because the

driver loaded the world selected in OT-0305, while the subject's current
projection names a later environment. Resolving the provider archive by the
current epoch id removes that experiment-specific choice.

corrected resolver requires exact provider bytes only for live projected
surfaces and verifies every evolved epoch source against its own retained
digest. Three malformed controls still fail closed. No actor was opened during
either correction.

The first live operation then passed every actor, selection, world, identity,
and continuation check but was rejected by OT-0310's obsolete proxy that
defined a fresh workspace as any path outside the repository. The current
apparatus intentionally stores fresh independent Git workspaces under ignored
`.evidence/`; G10 verified this actor's effects and trace as clean. The repair
checks the actual retained workspace identity, independent Git root, seed
separation, and exact clean audit. It reconstructs the completed selection and
2/6 world receipt without resampling, then resumes at operation two. Missing
Git identity and ambiguous-workspace fixtures fail before continuation.
