## Hypothesis

Actor-facing contradiction can become a subject-derived repair operation rather
than requiring an observer to edit the state or warn the next actor. A generic
coherence check can detect disagreement among opportunity count, derived phase,
and active continuation narrative; repair only non-authoritative narrative;
then return the exact subject to its already live pursuit.

## Frozen mechanism and gates

The coherence check applies only during the assimilated, no-offer, no-wait
opportunity phase. Machine state is valid only when projection count equals the
opportunity list, status agrees with zero/nonzero count, and inherited derivation
agrees with saturation or selection. Invalid machine state fails closed as
`reject-actor-facing-incoherence`; it is never repaired by changing prose.

When machine state is valid but active `continuation.next_opening` or
`unresolved` narrative disagrees, the same content-free entry derives
`repair-actor-facing-coherence`. The actor-free compiler changes only those two
fields, retains a non-authoritative repair receipt, reseals the subject, and
must restore the inherited operation. It has no actor, selection, world,
scoring, or admission authority.

Preflight freezes stale and coherent controls for 0, 1, 2, and 3 opportunities.
Every stale branch must derive repair, change only narrative, remain conformant,
and restore the correct operation; every coherent control must reject repair
and remain on its inherited operation. A count/list mutant must fail closed.
The exact parent must reproduce the observed two-versus-sole mismatch, repair
to `expanded-select`, and generate a prospective selection seed whose exact
projection, active subject narrative, summary, and cardinality-neutral README
agree. Route 16/16 and identity 18/18 remain floors.

The cheapest falsifiers are a change to authoritative opportunity or ledger
state, repair of malformed machine state, actor invocation, failure to repair
the exact mismatch, contradiction in the prospective actor seed, or failure to
return to selection. Preflight passes with receipt `e66615b7...`. Live output
remains sealed until this apparatus and record are committed and pushed.

## Limits fixed before output

A pass establishes one generic actor-free state-coherence repair and removes
one source of hidden observer dependence. It does not show that the subject
invented the checker, that all possible actor-facing contradictions are
detectable, or that the repaired narrative changes actor behavior.
