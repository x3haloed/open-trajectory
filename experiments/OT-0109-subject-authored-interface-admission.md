## Frozen hypothesis and cheapest falsifier

The exact subject's opening is sufficient to cause a fresh actor to author a
genuinely new, executable, reversible joint-capability interface; independent
authority can admit and use it; and a later fresh actor can ground another exact
open successor in the resulting consequence.

The cheapest falsifier is failure at any link: no conformant package, no new
consequential boundary, public-contract disagreement, hidden oracle mismatch,
invalid tool trace, ungrounded assimilation, or no exact open successor. A
proposal or plausible source file without admitted execution does not pass.

## Actor-visible package contract

Give the package author the exact parent projection, its bound continuation
action and opening, the retained joint capability, and a public meta-contract.
Do not supply candidate interfaces or boundary names.

The actor may change exactly four initially empty files:

- `interface.json` declares the exact interface id
  `joint-capability-frontier`, one new lowercase-snake-case numeric context
  field, one different new lowercase-snake-case numeric option field, inclusive
  bounds within `0..100`, and the score composition
  `joint_score - context_penalty * option_burden`;
- `operation.py` exports `choose_frontier(context, options)`;
- `conformance.py` exports `validate_contact(value)` as the package's public
  executable contract; and
- `contact.json` contains exactly three unique two-option cases.

The new field names must not duplicate any registered joint context or option
field. Ids retain OT-0108 semantics. The package must be reversible: setting
the new penalty or burden to zero recovers the registered joint scorer and
removing the new fields leaves a valid registered joint case.

The three authored cases must stay within declared bounds, exercise nonzero
new penalty and burden, include at least one case where the new term changes
the base joint winner, and include at least one nonzero extended-score margin
within the published boundary width. These are public requirements.

The actor has ordinary broad tools in an isolated workspace. Retain its full
tool trace, normalize path effects, and reject access to protected evidence,
hidden fixtures, acceptance state, or sibling workspaces. Exact four-file
mutation, complete trace, and truthful reporting are mandatory.

## Bind, admit, and use

Freeze and run conformance fixtures against the real independent validator and
scorer before actor authorization. They must accept one known-good package and
reject at least: an old-field collision, mixed id types, a vacuous public
validator, a non-reversible operation, and a package whose new boundary never
changes a winner.

After the actor finishes, audit and bind the exact four-file package before
creating any hidden cases. Generate one private hidden seed only after binding;
retain its digest and use a single deterministic derivation attempt to create
disjoint cases. The actor never sees the seed, cases, oracle rows, or score.

Independent admission requires:

1. exact schema, novelty, bounds, and authored-case coverage;
2. the public `validate_contact` agreeing with the independent validator on the
   authored contact and frozen valid/invalid mutations;
3. `choose_frontier` matching the independent composed-score oracle on all
   three authored cases and all hidden derived cases; and
4. zeroed-new-boundary and field-removal reversibility checks against the exact
   retained joint capability.

If admitted, register the bound package under independent authority and execute
its exact authored contact as the subject's requested world encounter. The
world receipt names every selected id, oracle id, and score. Actor self-report
is not evidence for admission or consequence.

## Assimilation, promotion, and stopping

Only after admitted use, give one fresh assimilator the exact parent, full
developmental projection, bound package, admission receipt, and world receipt.
It may change only grounded assimilation, successor-opening, and
continuation-action artifacts. It may bind the newly admitted interface, a
different registry extension, or a registered contact; no choice is mandatory.

Promote only if citations are exact, retained machinery and the admitted
package are byte-identical, liveness is mechanically derived, the package is
present in the successor registry and capability set, and the successor is
sounding and open. Freeze the exact successor before any later comparison.

Reject without repair or resampling on any failed gate and reopen the exact
OT-0108 parent. Stop after the operational path. Passing would establish one
bounded subject-authored registry expansion through independent admission and
use. It would not establish open-domain interface invention, autonomous
admission authority, selection frequency, or indefinite continuation.

## Result

Three implementation defects stopped before model inference and were repaired
without consuming the scientific actor: the inherited history projector did
not recognize newer continuation-action receipts, and the hosted response
schema subset rejected two otherwise valid JSON Schema constructs. Their raw
traces are retained separately.

The single package actor then completed cleanly, changed exactly the four
authorized files, and reported them truthfully. It chose `context_penalty` and
`option_burden`, authored a strict-looking validator, implemented the composed
score, and produced three unique cases.

The package was rejected before binding. Its `reversible_projection` value was
a truthful descriptive string, while the independent validator required the
undisclosed literal Boolean `true`. This is an apparatus ABI defect, not
evidence against package reversibility. Post hoc replacement of only that value
with `true` makes the exact contact pass every coverage gate; the exact
operation matches the independent oracle on all three cases and passes every
zero-boundary reversibility check.

A second, substantive defect remains: the actor-authored public validator
checks nonnegativity but omits the published upper bounds, so it accepts the
frozen out-of-range mutation. Under the frozen no-repair rule, no package was
bound, no hidden seed was generated, and no world or assimilation actor ran.
The exact OT-0108 subject remains open. The next experiment should repair the
apparatus type boundary, carry the exact package and explicit public-contract
failure into one fresh correction, and resume independent admission without a
replacement proposal.
