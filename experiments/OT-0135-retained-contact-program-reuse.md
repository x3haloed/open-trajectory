- **Status:** completed; operationally and causally promoted
- **Evidence class:** exploratory-only
- **Target:** make the exact admitted OT-0134 contact program a subject

## Frozen hypothesis

OT-0134 showed that an actor-authored metamorphic program can generate useful
contact across unseen bases, but its promoted subject retained only receipt and
route identities. If independently admitted contact programs become exact
subject capabilities, the current opening can mechanically select and compose
that retained program into the next contact. A later actor can then assimilate
new consequence without any actor reauthoring the listening instrument.

## Prospective capability retention

Materialize the exact OT-0134 subject and aggregate by manifest identity.
Require the admitted program, public and hidden receipts, binding, route, and
subject digest to pass exactly. Add one sealed `contact_program_capabilities`
entry containing:

- a capability id derived from the exact program digest;
- the exact program bytes and digest;
- source binding and admitted world-receipt identities;

- a fixed `ot-0135-joint-v1` composition interface.

This is a researcher-designed seed-substrate correction. It does not claim that
the subject invented its retention schema. The enriched subject must be exact,
sounding, open, and written before any new world contact.

## Continuation-owned reuse

A deterministic scheduler reads only the enriched subject. It binds reuse when
the exact opening asks about multiple foreign-context insertions and an exact
admitted reserve program is present. It does not consult an observer-selected
contact catalog or authorize a program-author actor.

Compiler `ot-0135-joint-v1` applies the retained high/low offsets and foreign
prefix to three sealed new bases. For each base it generates:

1. two foreign insertions at both extremes;
2. two foreign insertions at the high boundary; and
3. two foreign midpoint controls.

Bind capability reuse before revealing base values or outputs. Independent
consequence passes only if all six adversarial variants distinguish installed
from context-local reference behavior and all three controls confirm.

Only then authorize one fresh route actor. It must cite all nine exact cases,
select `extend`, retain the selector and contact-program capability bytes, and
produce a new uncertainty. Fixed route-only compiler `ot-0130-v1` derives the
cycle-six action and opening.

## Byte-erased control and stopping

Seal the operational successor before evaluating a deterministic control with
the same enriched subject, opening, receipts, and capability metadata but no
program bytes. The same scheduler must be unable to bind contact. The control
cannot veto the lineage.

Reject on any identity, retention, scheduling, hidden consequence, route,
compiler, or promotion failure. No replacement actor or program is allowed.

Passing would establish one bounded causal path where an admitted actor-authored
world-contact generator becomes subject state and is reused across later turns
without reauthoring. It would not establish subject-authored retention machinery,
arbitrary contact composition, frequency, indefinite operation, or autonomous
world/admission authority.
